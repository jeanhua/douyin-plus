工作原理

  1. 扩展在页面 MAIN world 注入网络拦截器，劫持 fetch 与 XMLHttpRequest，直接过滤抖音弹幕（/aweme/v1/web/danmaku/*）与评论 （/aweme/v1/web/comment/*）接口返回的 JSON。选择「隐藏」的规则命中后， 内容在渲染前就消失，不会占位、不会闪烁；「模糊」的规则则保留内容，由页面内的过滤器加模糊效果。
  2. ISOLATED world 的 DOM 过滤器做兜底，处理 WebSocket 直播弹幕、缓存数据等绕过接口的场景。
  3. 规则改动通过 window.postMessage 从扩展世界下发给拦截器，改完立即生效，无需刷新页面。

匹配说明

  • 关键词：一条规则可写多个词，用换行或逗号分隔，命中任意一个即屏蔽。
  • 正则：JavaScript 语法，不加 /.../ 两侧的斜杠，例如 1[3-9]\d{9}。
  • 场景：弹幕、评论、直播弹幕可分别勾选，精确控制生效范围。
  • 动作：隐藏 直接不显示；模糊 保留位置、鼠标悬停可临时查看，适合剧透类。

规则格式

完整格式说明见仓库里的 docs/RULES.md。

{
  "schema": "douyin-plus/ruleset",
  "name": "我的规则",
  "version": 1,
  "rules": [
    { "name": "广告", "type": "keyword", "pattern": "加微信\n刷单",
      "targets": { "comment": true, "danmaku": true }, "action": "hide" },
    { "name": "手机号", "type": "regex", "pattern": "1[3-9]\\d{9}",
      "targets": ["comment"], "action": "hide" }
  ]
}
